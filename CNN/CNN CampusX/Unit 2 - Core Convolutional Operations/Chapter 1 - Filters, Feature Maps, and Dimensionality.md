# 1. Introduction

To avoid flattening an image and losing its 2D spatial information, CNNs do not use fully connected neurons for their initial layers. 

Instead, they use a completely different approach based on small matrices called **Filters** (also known as **Kernels**).

---

# 2. What is a Filter (Kernel)?

A Filter is a small 2D grid of numbers (weights). 

Usually, the size of a filter is $ 3 \times 3 $ or $ 5 \times 5 $. 

These weights are not randomly updated; they are the **learnable parameters** of the CNN. The network learns what numbers to put inside the filter during backpropagation.

```text
Example 3x3 Filter:
[  1,  0, -1 ]
[  1,  0, -1 ]
[  1,  0, -1 ]
```

### The Purpose of a Filter
The purpose of a filter is to act as a **feature detector**. 

By dragging this small filter across the larger image, the CNN can detect specific patterns. For example, the filter shown above is a classic **Vertical Edge Detector**. If you multiply it against an image, it will highlight all the vertical lines and ignore everything else.

A CNN will typically use multiple filters (e.g., 32 or 64 filters in a single layer). 
- Filter 1 might learn to detect horizontal edges.
- Filter 2 might learn to detect diagonal edges.
- Filter 3 might learn to detect red color blobs.

---

# 3. What is a Feature Map?

When we apply a Filter to an Input Image, it produces a new 2D grid of numbers. This new grid is called a **Feature Map**.

A Feature Map represents the locations in the original image where the specific feature (e.g., a vertical edge) was successfully detected.

```text
Input Image  +  Filter  =  Feature Map
```

If a layer has 32 filters, it will produce 32 separate Feature Maps. These 32 maps are stacked together and passed as the input to the next layer in the network.

---

# 4. Dimensionality

In mathematics, Convolution involves matrices. Therefore, we need to understand the dimensions of the matrices we are working with.

### Grayscale Images
A grayscale image has only one color channel (light intensity).
- **Dimension:** $ n \times n $ (e.g., $ 28 \times 28 $)
- **Channels:** 1

When convolving a grayscale image, the filter must also be 2D: $ f \times f $ (e.g., $ 3 \times 3 $).

### RGB Color Images
A color image has three color channels: Red, Green, and Blue.
- **Dimension:** $ n \times n \times c $ (e.g., $ 64 \times 64 \times 3 $)
- **Channels ($c$):** 3

When convolving a 3D color image, **the filter must have the same number of channels as the input**. 
Therefore, the filter is a 3D volume: $ f \times f \times c $ (e.g., $ 3 \times 3 \times 3 $).

Even though the filter is 3D, applying it to a 3D image still produces a **2D Feature Map** (because the convolution sums the results across all channels).

# Interview Questions

## Q1. What is the difference between a Filter and a Feature Map?

**Answer**
A Filter (or Kernel) is a small grid of learnable weights used to detect a specific pattern (like an edge). A Feature Map is the output generated by sliding that filter across the input image. It represents where in the image that specific feature was detected.

---

## Q2. If an input image has dimensions $ 224 \times 224 \times 3 $, what must be the depth (channels) of the filter?

**Answer**
The filter must have exactly 3 channels to match the depth of the input image. Thus, a valid filter size would be $ 3 \times 3 \times 3 $.

---

# Summary

Filters are the core mechanism of a CNN, acting as local feature detectors. By preserving the 2D structure of the image, filters can detect edges and shapes regardless of where they appear. Applying a filter to an image results in a Feature Map, which is then passed deeper into the network.

---

# Key Takeaways

✔ CNNs use Filters instead of fully connected neurons.
✔ Filters are small matrices of learnable weights.
✔ Applying a filter produces a Feature Map.
✔ The number of channels in a filter must always match the number of channels in the input image.
