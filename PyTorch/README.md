# PyTorch Practice

This folder contains hands-on PyTorch implementations of the deep learning concepts covered in the theoretical notes.

## Learning Roadmap
1. Stage 1: Basic Tensors and Perceptron from scratch.
2. Stage 2: `nn.Module`, Multi-Layer Perceptrons, and Training Loops.
3. Stage 3: Computer Vision (CNNs).
4. Stage 4: Sequence Data (RNN, LSTM, GRU).
5. Stage 5: Transformers (Self-Attention, Masked Attention).
