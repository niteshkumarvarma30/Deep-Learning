# 1. Introduction

A neural network has one primary objective:

> **Given an input, produce the correct output.**

For example,

Input

```text
Image
```

↓

Output

```text
Cat
```

or

Input

```text
Customer Details
```

↓

Output

```text
Loan Approved
```

The question is

**How does the neural network produce this prediction?**

The answer is

**Forward Propagation.**

---

# 2. What is Forward Propagation?

## Definition

Forward Propagation is the process of passing information from the **Input Layer**, through all **Hidden Layers**, to the **Output Layer** in order to generate a prediction.

It is the first computation performed by every neural network.

---

# 3. Why is it Called Forward Propagation?

Information always moves in one direction.

```text
Input Layer

↓

Hidden Layer 1

↓

Hidden Layer 2

↓

Output Layer
```

Notice that information moves only

```text
Forward
```

There is no backward movement during prediction.

Hence the name

**Forward Propagation.**

---

# 4. Goal of Forward Propagation

The purpose of Forward Propagation is

- Compute the output of every neuron.
- Produce the final prediction.
- Pass information layer by layer.

It does **not** update any weights.

It only performs computation.

---

# 5. Real-Life Analogy

Consider a manufacturing factory.

```text
Raw Material

↓

Cutting

↓

Painting

↓

Assembly

↓

Finished Product
```

Each stage performs one specific operation.

The output of one stage becomes the input to the next stage.

A neural network works exactly the same way.

```text
Input

↓

Layer 1

↓

Layer 2

↓

Output
```

Each layer processes the information before sending it to the next layer.

---

# 6. What Actually Moves?

Many beginners think

> Weights move through the network.

This is incorrect.

Weights remain fixed during Forward Propagation.

The values that move through the network are the

**Outputs (Activations)**

generated by each neuron.

---

## Example

Suppose the input is

```text
[5,2,8]
```

The first hidden layer processes these values and produces

```text
[0.8,0.4,0.9]
```

These outputs become the inputs to the second hidden layer.

The second hidden layer produces

```text
[0.3,0.7]
```

Finally,

the output layer predicts

```text
Dog
```

The information is gradually transformed as it moves through the network.

---

# 7. Information Flow

The sequence of operations is

```text
Input Features

↓

Weighted Sum

↓

Bias Addition

↓

Activation Function

↓

Output of Current Layer

↓

Input to Next Layer

↓

Repeat

↓

Final Prediction
```

This process is repeated for every layer.

---

# 8. Mathematical Flow

Suppose

Input

$$
x
$$

The first hidden layer computes

$$
z^{(1)}=W^{(1)}x+b^{(1)}
$$

Apply activation

$$
a^{(1)}=f(z^{(1)})
$$

The activation becomes the input to the next layer.

Second hidden layer

$$
z^{(2)}=W^{(2)}a^{(1)}+b^{(2)}
$$

Apply activation

$$
a^{(2)}=f(z^{(2)})
$$

Output layer

$$
z^{(3)}=W^{(3)}a^{(2)}+b^{(3)}
$$

Final prediction

$$
\hat{y}=f(z^{(3)})
$$

---

# 9. Layer-by-Layer Computation

Suppose the network architecture is

```text
Layer 0

4 Neurons

↓

Layer 1

3 Neurons

↓

Layer 2

2 Neurons

↓

Layer 3

1 Neuron
```

---

## Step 1

### Input Layer

Receives

```text
x₁

x₂

x₃

x₄
```

No computation occurs.

The input layer simply forwards the data.

---

## Step 2

### Hidden Layer 1

Each neuron performs

```text
Weighted Sum

↓

Activation Function
```

Outputs

```text
o₁₁

o₁₂

o₁₃
```

---

## Step 3

### Hidden Layer 2

Inputs

```text
o₁₁

o₁₂

o₁₃
```

Each neuron again computes

```text
Weighted Sum

↓

Activation Function
```

Outputs

```text
o₂₁

o₂₂
```

---

## Step 4

### Output Layer

Inputs

```text
o₂₁

o₂₂
```

Computes

```text
Weighted Sum

↓

Activation Function
```

Produces

```text
o₃₁
```

or

$$
\hat{y}
$$

which is the final prediction.

---

# 10. General Computation at Every Layer

Every layer performs the same two operations.

### Step 1

Linear Transformation

$$
z=Wx+b
$$

---

### Step 2

Activation Function

$$
a=f(z)
$$

---

### Step 3

Pass the activation to the next layer.

This sequence continues until the final output layer.

---

# 11. Does Forward Propagation Train the Network?

No.

Forward Propagation only computes predictions.

Example

Actual Label

```text
Cat
```

Predicted Label

```text
Dog
```

Forward Propagation simply tells us

```text
Prediction = Dog
```

It does **not**

- update weights,
- change biases,
- reduce errors.

Learning starts only after the prediction is compared with the actual output.

That process is performed using

- Loss Function
- Backpropagation
- Gradient Descent

---

# 12. Real-Life Analogy

Consider a school examination.

```text
Student Writes Exam

↓

Teacher Checks Paper

↓

Marks Assigned

↓

Student Learns from Mistakes
```

Forward Propagation corresponds only to

```text
Student Writes Exam
```

Learning happens afterwards.

---

# 13. Why is Forward Propagation Important?

Every neural network performs Forward Propagation before learning.

Examples

- Artificial Neural Networks (ANN)
- Convolutional Neural Networks (CNN)
- Recurrent Neural Networks (RNN)
- Long Short-Term Memory (LSTM)
- Transformers
- GPT Models

Although their architectures differ,

they all begin by computing predictions through Forward Propagation.

---

# Summary

Forward Propagation is the process of computing predictions by passing information from the **Input Layer** through all **Hidden Layers** to the **Output Layer**.

At every layer, the network performs

1. Weighted Sum
2. Bias Addition
3. Activation Function
4. Pass Output to the Next Layer

This process continues until the network produces the final prediction.

Forward Propagation does **not** update weights.

It is only the **prediction phase** of a neural network.

---

# Key Takeaways

✔ Forward Propagation moves information from input to output.

✔ Information always flows in the forward direction.

✔ Weights remain fixed during Forward Propagation.

✔ Outputs (activations) are passed from one layer to the next.

✔ Every layer performs two fundamental computations:

- Linear Transformation

$$
z=Wx+b
$$

- Activation Function

$$
a=f(z)
$$

✔ Forward Propagation produces predictions but does not train the network.

✔ Learning begins only after computing the loss and performing Backpropagation.
